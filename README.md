# Low Ticket Sales Pages

Projeto-base para desenvolver, testar e organizar páginas de vendas de produtos low ticket.

## Tecnologias

- Vite
- TypeScript
- HTML e CSS

## Como executar

```bash
npm install
npm run dev
```

## Como gerar a versão de produção

```bash
npm run build
npm run preview
```

## Estrutura

- `index.html`: documento principal
- `src/main.ts`: ponto de entrada da aplicação
- `src/style.css`: estilos globais
- `vite.config.ts`: configuração do Vite
- `tsconfig.json`: configuração do TypeScript
